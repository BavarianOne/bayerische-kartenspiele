🏗️ Türme von Hanoi

🎯 Ziel

Bewege alle Scheiben von Turm A zu Turm C.

📜 Regeln

  • Nur eine Scheibe auf einmal bewegen
  • Eine Scheibe darf nur auf eine größere gelegt werden
  • Turm B ist der Hilfsturm

🎮 Steuerung

  • Tap: Wähle Turm A, dann Turm B oder C
  • ↩️: Rückgängig machen
  • 💡: Tipp anzeigen
  • Neu: Spiel zurücksetzen

🧠 Tipp

Bewege immer die kleinste Scheibe im Zyklus A→B→C→A...
